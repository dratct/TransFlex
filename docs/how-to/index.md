# How-To

How-to docs are recipes for known tasks.

- [Development Workflows](development-workflows.md): build, test, run, configure providers, manage presets, reset onboarding, and stream logs.
- [Release](release.md): create signed and notarized releases, review draft prereleases, and configure the signing credentials.
- [Sparkle Update Key](sparkle-signing-key.md): make the key pair that signs auto updates, store it, and replace it if lost.
