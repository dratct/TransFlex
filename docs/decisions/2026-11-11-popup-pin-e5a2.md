# The popup can be pinned for one open

Status: accepted — 2026-11-11

## Context

The popup hides as soon as another app comes forward, and every open computes
its frame again. That suits a translation read once. It does not suit a
translation kept beside the work: text typed from it into another app, or a
long result read while writing a reply. A three-role review of the popup
(product, design, engineering) proposed a pin, and the owner settled the open
points.

## Decision

- A Pin button in the popup header, and ⌘P while the popup has the keyboard,
  pin the popup. Pinned, it is not hidden when another app comes forward or
  the user clicks elsewhere, and it keeps its top-left corner where it was
  dragged, through growth and ⌘I.
- The pin lasts one open and is never saved. Every way of hiding the popup
  ends it, Copy & Close included; Translate again from History ends it too
  and opens the Popup at its usual place.
- A pinned popup shows a Close button, because Esc does not always close.
- While pinned, Translate Selection is refused: nothing is copied and a
  banner says "The popup is pinned" / "Unpin it to translate a new
  selection."
- While pinned, Replace Selection runs and leaves the popup alone. Its
  failure uses the Replace banner. Only the Accessibility permission card,
  and the error after Open Popup is pressed on that banner, show in the
  pinned popup.
- A translation that fails inside a pinned Output-only popup before any text
  arrives keeps its error card with Retry in the popup.

## Consequences

- The panel joins every Space, so a forgotten pinned popup follows the user
  until it is closed.
- While a pinned popup is showing, Esc is held system-wide for the length of
  a Replace run and of its failure banner. The rule in
  2026-11-10-ux-audit-popup-rules-a856 that a Replace failure with the Popup
  open shows in the Popup, so the first Esc still reaches it, now holds only
  for a popup that is not pinned.
- Replace Selection pressed while the pinned popup has the keyboard orders
  the panel out and back in, so ⌘C reaches the other app.
- Clicking the pinned popup during a Replace run sends the paste to the
  popup, and that run fails under
  2026-11-06-replace-selection-checks-the-field-changed-5c2e.
- A pinned popup dragged partly off screen is clamped only at the bottom
  edge when it grows; ⌘I moves it back on screen.

## Rejected

- Translate Selection replacing the pinned content in place: the pinned
  translation is the thing the user asked to keep.
- Remembering the pin or the dragged position across opens: a popup that
  opens somewhere unexpected, or does not go away, is worse than pinning
  again.
- A second panel, or several pinned popups: one warm panel is what keeps
  opening fast.
