title: Images
description: Translate the text in a screenshot or a photo.
---

The Popup can translate the text in an image: a screenshot, a photo of a sign, a scanned page.

## Turn it on

A preset reads images only when you say its model can. In **Settings → Presets**, pick the preset and turn on **Reads images**. The built-in presets start with it off.

Use a model that accepts images. If the preset cannot read images, the Popup tells you so instead of sending the picture.

## Add an image

Open the Popup with <kbd>⌥</kbd> <kbd>T</kbd>, then do one of these:

- Drag an image onto the **Original** side.
- Copy an image and press <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>V</kbd>.
- Press <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>O</kbd> and choose a file.

Then press <kbd>⌘</kbd> <kbd>⏎</kbd>. The **×** on the image removes it.

## Limits

- Formats: PNG, JPEG, GIF, WebP, HEIC, TIFF, BMP.
- At most 20 MB and 50 megapixels.
- Images work in the Popup only. Translate selection and Replace selection handle text.
- An image usually costs more than a line of text.

History keeps the translation of an image, but never the image itself.
